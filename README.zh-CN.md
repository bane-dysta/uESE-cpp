# uese-cpp：基于 2021 年 uESE 模型的 C++17 实现

这是可独立编译、运行的 uESE 溶剂化自由能计算程序。输入为**气相几何和气相 CM5 原子电荷**，输出 COSMO 静电项、各项经验校正及总溶剂化自由能，单位为 kcal/mol。主程序仅使用 C++17 标准库。

公式和元素参数对应 Vyboishchikov 与 Voityuk 的 2021 年论文，DOI [10.1002/jcc.26531](https://doi.org/10.1002/jcc.26531)，式 (4)–(12) 与 Table 1。内置 92 种溶剂的介电常数、分类和溶剂偏移参数。**2021 Supporting Information 的 Table S1 已逐项核对 20 种 C 类、57 种 D 类溶剂的全部 77 个 \(\xi_{\mathrm{solv}}\) 参数，和此前从作者 uESE v1.2 程序提取的值完全一致。** 介电常数 \(\epsilon\) 仍来自作者 uESE v1.2 程序，而非 Table S1（该表没有介电常数列）。方程、参数和验证的来源均保存在项目中。详细核验见 [论文与源码对照报告](docs/PAPER_CROSSCHECK.zh-CN.md)。

本次 v1.1 已在 Linux / GCC 13.3.0 上编译并通过 **1386 项断言**，包括作者程序的数值回归、全部已发表元素参数覆盖、物理极限、单位解析和异常输入。结果及适用边界见 [验证报告](docs/VALIDATION.zh-CN.md)。Windows 与 macOS 的构建方式已提供，但未在这些系统实际运行验证。

## 1. 编译并运行附件中的例子

解压后进入 `uese_cpp` 文件夹。Linux 或已安装 Make 的环境：

```bash
make
./uese examples/PhO_minus.inp -solvent acetonitrile
```

也可以直接用支持 C++17 的编译器，省去 Make：

```bash
g++ -O3 -std=c++17 -Iinclude src/main.cpp src/io.cpp src/model.cpp src/output.cpp src/parameters.cpp src/surface.cpp -o uese
```

Windows / MinGW 可把末尾改为 `-o uese.exe`，然后运行：

```powershell
.\uese.exe examples\PhO_minus.inp -solvent acetonitrile
```

CMake 构建：

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

Linux 常见输出路径是 `build/uese`；Visual Studio 多配置构建常见路径是 `build/Release/uese.exe`。本程序运行时不依赖 Python、GDB、原版 uESE 或网络。Python 3 仅用于运行项目测试。

### 例子结果

`PhO_minus.inp` 保留上传文件中的几何与 CM5 电荷，默认 `NDIV=3`、不居中。乙腈计算的关键结果：

```text
Atoms: 12
Surface points: 387
Cavity area [angstrom^2]: 115.71379003
Cavity volume [angstrom^3]: 89.30238399
COSMO electrostatic: -66.94496465
Correction total:    12.39460347
TOTAL SOLVATION:    -54.55036118
```

附件旧版输出中的总能量是 −54.554 kcal/mol，本程序与该打印值相差约 +0.003639 kcal/mol。该差异没有通过调参数或硬编码例子消除。

## 2. 输入格式

### 原版 uESE / Multiwfn 格式

可直接读取上传文件使用的结构：

```text
Generated by Multiwfn
Atomic coordinates
<atomic-number or symbol>  <x>  <y>  <z>
...one row per atom...

Ground state charges
<q1> <q2> ... <qN>
```

电荷可以跨多行，但个数必须与原子数相等。上面的尖括号内容是格式说明；可直接运行的完整文件在 `examples/`。默认坐标为 Å，电荷以基本电荷 e 为单位。支持 Fortran 的 `D` 指数。

### 带电荷的扩展 XYZ

第一行为原子数，第二行为标题，随后每行为 `元素 x y z 电荷`，共五列。普通只含四列的 XYZ 不含电荷，不能直接计算本模型。也可省略头两行，使用纯五列文件。

在适当的单位声明位置可使用 `units=bohr`、`units=angstrom` 或 `atomic_units`；最明确的方式是命令行覆盖：

```bash
./uese input.xyzq --units bohr --solvent water
```

自动模式会拒绝冲突的单位声明。普通标题中提及 “atomic units” 不会触发隐式换算。完整参数解析规则可见 `src/io.cpp`。

**输入电荷需由量子化学计算得到。** 本程序不会从分子几何生成 CM5 电荷，也不会将 Mulliken、Hirshfeld 或 ESP 电荷自动转换成 CM5。它保留输入电荷值，不强制归一化到整数。例如官方 NH₃ 示例因四位小数截断而总电荷为 +0.0001 e，该数值被原样保留。

## 3. 选择溶剂及导出结果

```bash
./uese examples/PhO_minus.inp --solvent water
./uese examples/PhO_minus.inp --solvent methanol
./uese examples/PhO_minus.inp --solvent MeCN
./uese examples/PhO_minus.inp --solvent DMSO
./uese examples/PhO_minus.inp --solvent benzene
./uese --list-solvents
```

名称匹配忽略大小写、空格、连字符和下划线，并支持作者列表中的别名及 SI 中的 `diphenyl ether`、`tert-butylbenzene`。`--list-solvents` 输出完整参数及其来源。

JSON 方便接入现有量化化学工作流：

```bash
./uese examples/PhO_minus.inp --solvent acetonitrile --format json > result.json
```

导出每个表面片的位置、法向、面积、诱导电荷与密度：

```bash
./uese examples/PhO_minus.inp --solvent acetonitrile --surface surface.csv
```

导出的表面电荷是**未乘介电因子的导体极限电荷**，与原文校正项所用变量一致。程序会拒绝将表面文件写回同一个输入文件。

对于用户已有完整参数的新溶剂，可显式指定：

```bash
./uese examples/PhO_minus.inp --class C --epsilon 35.6881 --xi 0.0021
```

此例与内置乙腈参数一致。C/D 类自定义溶剂必须提供 `--xi`；不会把缺失值默认为零。`--xi 0` 表示用户明确选择无溶剂偏移的变体，应在使用结果时记录。A/B 类公式没有此项。

## 4. 支持的元素与重要边界

| 溶剂类别 | 完整 uESE 支持的元素 |
| --- | --- |
| A：水 | H、C、N、O、F、P、S、Cl、Br、I |
| B：非水极性质子溶剂 | H、C、N、O、F、P、S、Cl、Br、I |
| C：极性非质子溶剂 | H、C、N、O、F、S、Cl、Br |
| D：非极性溶剂 | H、C、N、O、F、P、S、Cl、Br、I |

这是原文 Table 1 的覆盖范围。**B、Au 未给出校正参数，C 类的 P、I 列也为空白。** 代码会拒绝这些完整模型请求，不能将缺参数的元素当作校正为零。`examples/B2H6.inp` 和 `examples/Au20.inp` 作为这一边界的示例保留。

若仅研究静电贡献，可以显式运行：

```bash
./uese examples/Au20.inp --solvent water --electrostatic-only
```

该模式不报告完整溶剂化总能。B 和 Au 的默认半径分别为 1.92 和 1.66 Å，来源是作者程序输出。对没有已核验半径的元素，可在静电模式显式给出 `--radius Fe=1.80`；这属于用户指定的空腔模型，不表示论文已验证该元素。

以下选项应和结果一起记录：

- `--ndiv 1..5`：默认 3。改变子采样密度会改变遮蔽判断和表面片位置，不等于对完整 COSMO 电荷网格做了收敛，也未重新拟合参数。
- `--center`：默认关闭。显式把坐标移到几何中心；有限网格的体积积分有原点敏感性，因此居中可能改变结果。
- `--radius Element=value`：修改半径意味着偏离原文不缩放的 Bondi 空腔。
- `--max-points N`：默认最多 6000 个表面电荷点。直接求解的存储量约为 `8*M*M` 字节，主要矩阵分解的计算量为 O(M³)。

本程序计算固定气相电荷的平衡溶剂化自由能，不包含气相 DFT、几何优化、解析梯度或激发态非平衡溶剂响应。输出不自动附加 1 atm / 1 mol/L 标准态转换常数。

## 5. 验证和程序结构

```bash
make test
```

或：

```bash
python3 tests/run_tests.py ./uese
```

已完成的对照包括：完整论文 Table 1、SI Table S1 的 77 项溶剂偏移参数，上传的 2021 年乙腈输出、作者新版的 92 种溶剂 PhO⁻ 结果、4 种溶剂的 NH₃ 结果、76 个元素/类别/电荷正负组合，以及单球解析极限、电荷二次齐次关系、单位、异常输入和表面导出检查。合成元素测试只检验实现与参数，不表示对真实化学体系的预测误差小于 0.01 kcal/mol。

C++ 库接口示例：

```cpp
#include "uese/model.hpp"
#include <iostream>

int main() {
    auto molecule = uese::read_molecule("examples/PhO_minus.inp");
    auto solvent = uese::find_solvent("acetonitrile");
    auto result = uese::calculate(molecule, solvent);
    std::cout << result.energy.total() << '\n';
}
```

在 CMake 中链接 `uese_core` 即可。使用科学结果时应引用原模型论文；本项目为独立源码实现，见 [NOTICE](NOTICE) 和 [LICENSE](LICENSE)。
