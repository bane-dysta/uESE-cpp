# uese-cpp 数值验证报告

验证日期：2026-10-28。编译环境：Linux x86-64、GCC 13.3.0、C++17，编译参数 `-O3 -Wall -Wextra -Wpedantic`；编译无警告。运行 `make test` 得到 **1386 项断言全部通过**。

本报告衡量本实现对公式、参数及作者程序的数值复现，不能解释为对实验溶剂化自由能的相同精度保证。以下误差单位均为 kcal/mol。

Table 1、SI Table S1 的全部 77 个溶剂偏移参数已逐项核对。

## 4. 全部已发表元素参数的合成覆盖

A/B/D 类各 10 个元素、C 类 8 个元素，每组分别使用正负电荷，合计 `(10+10+8+10)*2=76` 个测试。几何为同元素四个原子组成的紧凑四面体，每条边长为 `1.5*R`，每个原子电荷为 +0.37 e 或 −0.37 e，两套程序读取相同的八位小数坐标。

这种输入用于验证所有元素参数、符号、半径和公式分支；它不是有物理意义的分子数据集。原始参考和差值在 `tests/reference_2025_elements_76.tsv`。测试程序会重新生成相同几何。

| 比较项目 | 76 个结果的最大绝对差 |
| --- | ---: |
| 静电项 | 0.008167271216 |
| 校正项 | 0.004663835586 |
| 总能量 | **0.008194100739** |

所有半径和表面点数逐项相同。自动回归采用 0.01 的能量容差。

作者程序在所试孤立原子及相距很远的原子输入上在 GEPOL 阶段崩溃，所以不将其作为可比较参考；改用相交球的四面体后成功运行。C++ 对孤立球另用解析公式验证，未通过改动模型参数去适应参考程序的崩溃。

## 5. 物理与数值检查

- 孤立球的面积、体积分别满足 `4*pi*R^2` 和 `4*pi*R^3/3`。
- 半径 1.7 Å、中心单位电荷的导体能为约 −97.654040905，Born 解析值约 −97.665798029，相对离散误差约 0.012%。仍使用最多 60 个重归表面电荷点，不宣称解析值逐位相同。
- 固定几何把所有电荷乘 2，静电能乘 4；零电荷静电能为零；介电常数为 1 时静电能为零。
- 用于校正的导体电荷在不同溶剂间不再乘介电因子。
- PhO⁻ 原方程的归一化残差约为 `4.18e-16`。残差检查的是线性方程求解，不能代替表面离散误差检查。
- 单位转换、任意 XYZ 标题、Fortran D 指数、电荷计数、NaN、重合原子、完全埋藏原子、无效参数、未知溶剂、缺失拟合参数、JSON/CSV 一致性与禁止覆盖输入均已检查。
