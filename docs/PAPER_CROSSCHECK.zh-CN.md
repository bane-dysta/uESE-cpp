## 2. 公式和程序的明确映射

输入电荷 `Q_A` 与解出的表面诱导电荷 `q_i` 不同。按原子汇总 `q_A = sum_(i in A) q_i`，用原子暴露面积 `S_A` 构造 `σ_A = q_A/S_A`。程序在 `model.cpp` 中求解 `Aq=-V`，计算 `E_elst = 0.5 * K * f(ε) * Σ_i q_i V_i`，其中 `K=332.063713299` 用于 e、Å 到 kcal/mol 的单位换算。这一乘子不属于论文拟合参数。

- **A 水：** `Σ κ_A S_A + Σ p_A q_A² + SRC`。
- **B 极性质子：** 同上，加 `ζV`。
- **C 极性非质子：** `Σ (κ_A + ξ_solv) S_A + Σ g_A q_A + Σ p_A q_A² + ζV`。
- **D 非极性：** `Σ (κ_A + ξ_solv) S_A + Σ p_A |q_A| + ζV`。

SRC 在 A、B 类：`C * erf(A * |σ_min|³ + B * |σ_max|³)`；`σ_min/max` 是暴露原子平均诱导电荷密度的极值。`A`、`B`、`C` 名称为论文的 SRC 参数，不与溶剂类别混淆。参数和正文一致：A 类 `(68500,87700,-8.87)`，B 类 `(186000,78500,-2.36)`；体积项 `ζ=(0,-0.070,-0.236,-0.166)`。源码还把 Table 1 未给出值（如 C 类 P、I）视为**缺参数**，不擅自等于零。

GEPOL93 的表面离散、Bondi 半径及不加非原子中心平滑球，来自正文页 1186；源码是独立表面算法，和原始作者数值例子对得上，但不声称逐行复制了 GEPOL93。文中“32 tesserae per atom”与当前最接近作者结果的 **32 顶点/60 初始三角面** 的几何解释有术语差异，详见 `THEORY.zh-CN.md`。

## 3. SI Table S1 全部 77 个参数比对

`data/table_s1_xi.tsv` 按论文 SI 第 2 页的原始英文溶剂名记录 `si_name, class, xi, cpp_name`，共 C=20、D=57，总计 77。每一项和 `data/solvents.json` 中的浮点值差小于 1e-12，**没有数值不符、正负号错误或类别错误**。

注意原文分类并非现代溶剂类型的通用字典。例如 D 类包括乙酸、苯胺、四氢呋喃。C 类中的原始名字 `sulfolane` 在作者运行时使用 `tetrahydrothiophenedioxide`；D 类的 `dichloromethane` 对应作者名 `methylenechloride`。现有别名覆盖前两者；本次额外增加 `diphenyl ether` → `phenylether` 和 `tert-butylbenzene` → `tbutylbenzene`，保证 SI Table S1 的 77 个印刷名称都可被 CLI 接受。

**分开说明 ε：** 原文 Table S1 只有 \(\xi_{\mathrm{solv}}\) 数据，**并无 77 个介电常数的列表**。因此 `solvents.json` 中的 ε 值仍标为从作者公开 v1.2 可执行程序获得，不应错误归因于 SI。

## 4. SI 中的苯氧负离子 i074 与用户提供的示例不同

下列数值分别是 SI **i074** 项的论文值与本次提供的 `examples/PhO_minus.inp` 输入按 v1.1 公式直接算出的值；最后一列为 C++ 减去 SI。四行都使用相同标识的化学式 C6H5O⁻，**但 SI 未给出完整坐标和 CM5 电荷，故尚不能证明输入完全相同**。

| 溶剂 | SI i074 (kcal/mol) | 附件输入 C++ (kcal/mol) | 差 (kcal/mol) | 来源 |
|---|---:|---:|---:|---|
| 水 | -68.742 | -68.598907 | +0.143093 | SI Table S4, p.13 |
| 甲醇 | -67.114 | -66.973921 | +0.140079 | SI Table S22, p.28 |
| 乙腈 | -54.680 | -54.550361 | +0.129639 | SI Table S38, p.34 |
| DMSO | -55.348 | -55.217689 | +0.130311 | SI Table S45, p.36 |

这四个差值方向一致且在约 0.13–0.14 kcal/mol 范围，**不是“C++ 相对于同输入原版的数值误差”**。在完全相同的用户输入上，2021 作者程序的乙腈打印结果是 **−54.554**，本 C++ 是 **−54.550361**，差 **+0.003639 kcal/mol**。请区分这两种对照基准，不能根据 SI i074 的数字直接对模型调参。

SI p.14 Table S5 还列有五个分子的水相能量分解（静电、面积、电荷平方、SRC）。这些适合确认各项的物理含义及求和关系，但同样无法在缺少每个分子原始几何和 CM5 电荷时，作为严格的逐项数值回归输入。

## 5. 验证方法与局限

运行 `make test` 会完成旧版数值回归，并额外读取 **SI Table S1 的独立 TSV**，通过程序 `--list-solvents` 输出核对每条 C/D 溶剂的类别、xi 和来源；对 `diphenyl ether`、`tert-butylbenzene` 的 SI 别名会实际做计算。测试原版参考含作者 2021 苯氧负离子打印值、作者 2025 v1.2 的 92 溶剂和 76 组合成测试。其打印精度有限，不能声称计算达到了实验精度 0.01 kcal/mol。
